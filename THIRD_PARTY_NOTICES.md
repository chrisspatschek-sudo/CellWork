# Third-party notices

Cellwork is © 2026 Chris Spatschek and released under the MIT License (see `LICENSE`).

Cellwork's `index.html` bundles the following third-party components. Each is used
unmodified except where noted, and each licence permits redistribution in this form.

| Component | Version | Used for | Licence | Location in this repo |
|---|---|---|---|---|
| [d3-delaunay](https://github.com/d3/d3-delaunay) | 6.0.4 | Delaunay triangulation and Voronoi cells | ISC | `vendor/d3-delaunay.min.js` |
| [Delaunator](https://github.com/mapbox/delaunator) | 5.0.0 (bundled inside d3-delaunay) | Fast Delaunay triangulation | ISC | inside `vendor/d3-delaunay.min.js` |
| [robust-predicates](https://github.com/mourner/robust-predicates) | 3.x (bundled inside d3-delaunay) | Exact geometric predicates | Unlicense (public domain) | inside `vendor/d3-delaunay.min.js` |
| [Clipper](http://www.angusj.com/delphi/clipper.php), JavaScript port ([clipper-lib](https://www.npmjs.com/package/clipper-lib)) | 6.4.2 / 6.4.2.2 | Polygon offsetting and clipping | Boost Software License 1.0 | `vendor/clipper.min.js` (minified, original header kept) |
| [JSBN](http://www-cs-students.stanford.edu/~tjw/jsbn/) | (bundled inside Clipper JS) | Big-integer maths used by Clipper | JSBN licence (permissive) | inside `vendor/clipper.min.js` |
| [Instrument Sans](https://github.com/Instrument/instrument-sans) | Google Fonts build | Interface typeface | SIL Open Font License 1.1 | `fonts/InstrumentSans-latin.woff2`, licence in `licenses/instrument-sans-OFL.txt` |

Modifications: Clipper JS was minified with terser (its original copyright header is kept at
the top of the file). Instrument Sans was instanced to the regular width (weights 400–700),
subset to Latin characters and converted to WOFF2, keeping its copyright and licence metadata; the font declares no Reserved Font Name.

All licence texts are also kept as separate files in [`licenses/`](licenses/) and embedded in
`index.html` (in the `<script type="text/plain" id="licenses">` block, and via **Show licences**
in the app), so a copy of `index.html` on its own still carries every required notice.
